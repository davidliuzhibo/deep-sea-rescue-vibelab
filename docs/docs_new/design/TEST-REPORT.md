## 本轮发现并修复

- 原护送代理只包住身体，漏掉摆动鳍肢：改成37个蒙皮采样的非对称完整包络，扩大深度间距和17cm换道走廊；路线线段与真实三段路径一致。修前比较保存在 `route-envelope-before-fix.json`。
- 吊起后任意改气会产生不安全倾斜并可能越界：新增返回托架才可改气的保护。新用例在旧逻辑失败，在修复后通过。第二次用例的精确浮点零断言改为“未进一步移动”的断言，1e-18残差并非额外游戏故障。
- 引航灯、网笼和浮袋连接的视觉支承不足：增加支腿、静态托架、承重连接、平滑充气，航道岩石补为落地礁柱。保存修前图，最终用实际打包GLB离线重渲染审读。
- 新任务存档、阶段前置条件、结算记录、重开、暂停恢复和旧v1迁移均检查。非法绕过、错误路线、悬吊调气、后台操作和跳过动画不能提前完成任务。

历史编译失败（测试括号、词间空格）、修前测试失败和全部原始日志保留，未改写成成功记录。
