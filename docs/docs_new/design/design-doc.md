# 深海救援站：一条安全归途

本轮将品质片段扩展为完整四任务游戏，先完成全部离线工作，再安排设备验证。首次玩家目标15–25分钟是本轮工作假设，尚未实际计时；没有倒计时补时。核心离线，无业务服务器。

## 方向选择与两轮自审

三份独立探索位于 `.scratch/deep-sea-rescue-full-20261105/direction-*.md`。

|方向|任务效率与重玩|空间与题材|舒适性|风险|选择|
|连续值守|顺畅，但重玩要走全流程|同一海龟，环境因果强|单固定窗|后半仍大量绞盘，像重复片段|不采用线性锁定|
|四节点航图|清楚、可任选中间两项|不同设备判断，最后合流|复用单面板|容易像四个孤立关卡|采用主架构|
|栖息地重建|直接看世界变化|环境持续性最强|固定窗|扩成生态游戏，新增鱼群和礁体系统|采用持续修复成果，不扩新生态系统|

第一轮自审：单纯增加救援动物会重复剪绳；改成灯塔联动、偏载吊运与路线护送三种新判断。只保留一只Seed3D主角，精修设备与环境，不用低质新动物填关数。第二轮自审：任务图只在完成或暂停时出现，操作时唯一焦点是现场；增加具体提示、恢复和重开确认，避免任意切关丢失工作。设计预览是JSON领域示意，最终3D需原生另验。

## 完整内容与规则

1. **海龟解困**：保留三处检查、夹稳木梁、按序剪绳、挂浮袋、绕梁分段提升。正常抵达安全区后海龟游到等候区，第一项结束。
2. **修复引航灯**：检查电源与透镜，先断电再换电芯。三只导光轮各四格，转动一只同时带动右邻，最右连接最左。现场刻度目标1、3、2。只有真正对齐才进行3秒传光，三段连接全部亮起才结算。可双向调整、提示说明联动；不是快速点击游戏。
3. **双浮袋清障**：检查吊环和配重，分别挂袋。重侧需多一档气，总量5–6档，倾斜不超过4度方可提升。每次7cm，升到23cm后向右分段停放，抵达32cm停放区后明确锁定。过载或倾斜制动；升起后禁止改变气量，先移回中间并降回托架才能重新调气。首次右重、完成后重玩左重，配重模型随规则移动。
4. **归途护送**：前述灯亮且网笼已停放才开放。三处实体航标各有左/中/右路线，近段避右岩，中段绕左岩，出口避中央横流。以实际路径与障碍扫掠判定通行（含37个蒙皮动画采样的完整鳍肢范围；航标间留出17cm换道走廊）；海龟有限速度前进，逐段抵达再继续。受阻可停下改线，不跳关不伤害动物。最终实际抵达后告别，可跳过结尾动画。

完成解困后任务2/3任选先后；两项都完成才开放护送。正在进行的任务可离开、恢复、重开；切换到其他任务只在本次任务完成后开放，以避免无提示丢弃半途工作。重开需确认，只清当前尝试；总成果与最好记录保留。全部完成后自由重玩。记录只写完成、用时和安全制动，不宣称官方星级。

## 输入、空间、视觉

一个Mixed Stage、真实墙面Portal、可选真实桌面控制台、一个上下文AttachmentPanel；沿用已设计的固定坐标、250ms新鲜姿态与三角网格覆盖验证。控制台可不用。实际房间其余可见，虚拟练习明确标识。窗1.5×0.9m，深1.3m，主要任务接近平视；85%时间目标仍待真机测量。

面板默认820×660dp，原生固定尺寸；640/820/1000dp只做组件响应布局验证，不宣称系统可拖动缩放。内容可滚、主动作固定、最小触点56dp。PicoTheme保留16原生角色，标准SpatialUI按钮；仅文本叶节点使用可读表面。

全部任务用系统手势/眼手点击可完成。目标点选只高亮；机械臂有限速度对准，到位后明确操作。圆柄为受限平移备选，无精密腕转、无双手同时按住、无控制器依赖。新任务复用同一输入所有者/取消门禁。暂停、失追踪、后台停止全部运动，不恢复旧捏合或自动重新放行。

原Seed3D海龟、PBR龟壳与鳍肢动画保留。新增黄铜陶瓷引航灯、独立刻度轮、磨损网笼/配重、双浮袋、岩拱、航标。机械结构的变化直接对应规则；亮灯、清空航道和海龟路径留在最后场景。资产需独立边界/网格/资源校验、离线构图审读；这些不能替代原生材质与门户遮挡测试。

## 保存、错误与交付边界

v1旧文件保留，新v2校验封套原子写入；旧通关仅映射第一项。持久状态包括当前任务、阶段、工具、完成检查、联动轮、双袋/笼位、护送节点及总记录。暂停清临时移动目标，继续需重新发令，历史存档不存SDK平面ID。失败写入不显示成功。

所有任务有开始/操作/明确完成/记录/重玩；另有设置、帮助、暂停、退出确认、追踪恢复和资源错误。L01/L07对应判断和具体说明；L02/03/08/28/29沿用共同坐标、稳定墙面、无遮挡面板；L04–06/23意图边缘和取消；L09真实运动后成功；L10–12音频/资源/存档；L15–18无授权设备不执行且保留旧件；L19–27/30 JSON单源、实际控件、错误恢复、不同证据分层。完整映射与测试报告在实现后更新。
