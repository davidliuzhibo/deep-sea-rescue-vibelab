# 深海救援站：四任务集中原生验收计划

计划而非已执行记录。当前没有模拟器、ADB、屏幕或播放声音的授权；先交付全部后台成果，再由用户安排。本轮没有设备数据变更。

建议预留 **90–120分钟屏幕+模拟器**，包含备份与恢复。预计不是承诺；遇到明显需返修的代码/布局问题，留证据、恢复现场、交还屏幕，再到后台修改，不无限占屏。

| 预计时间 | 实际步骤与通过标准 |
|---|---|
| 5–10分钟 | 确认当前授权和AVD；备份当时安装包/私有数据并逐项哈希。旧记录只参考，不覆盖后来存档。安装code2，分别核对Activity启动、资源ready、头姿、真正可交互时间。 |
| 15–20分钟 | 以正常及非零起始朝向进入，检查前方墙面预览/确认/更换、可选桌面和明确的虚拟练习。观察Portal正面和侧面裁切、龟壳材质/动画、窗口与面板遮挡、各阶段文字滚动和底部按钮。不得将相机绕点移动当原地转头。 |
| 25–30分钟 | 用自然OS点击完整四任务：解困→灯轮联动→偏载清障→三段护送。用真实目标标记及面板选择，选中不得即执行。观测实际到位、动画/声音、三段光、笼子真实位移、海龟绕礁柱和最终结算。记录操作时长，不能以合成tick时长替代玩家时间。 |
| 15–20分钟 | 相反中段顺序的任务解锁/重玩；错误剪序、未断电、未对齐、偏载/吊起改气、错误路线、途中停航、暂停恢复、重开确认。测试存档退出/重启和结果不重复记。针对性夹具可节约重复开场，但必须明确记录，不能叫第二次完整人工通关。 |
| 10–15分钟 | 圆柄有意抓取、慢拖、松手、取消、后台/失追踪后重获，不自动重抓或自动继续。最多2次自动拖动无位移便核对事件；若工具不能保持长按，申请用户约30秒慢拖，先确认游戏可见再提步骤，无自动退出倒计时。完整点按路径仍为主。 |
| 10–15分钟 | 获准音量下试听BGM/音效独立开关、后台静音与恢复。读取ANR/崩溃、内存/帧表现；测数次启动并区分实际加载慢和工具捕获问题。可运行3项已编译AndroidTest，明确是合成姿态/生产命令和资源测试，不是光学输入。 |
| 10分钟 | 安装最终release、核对SHA、实际启动与关键修复点。恢复本次新备份并逐字节复核；如测试前不存在该包，只移除本次测试产生的数据/安装，按约定停止独立测试AVD，释放CU/CUA及残余指针，不再启动应用。 |

固定AttachmentPanel820×660dp，三档Web布局不代表支持原生系统角标缩放。点击/拖动/画面/声音未通过以前，本地107项不能证明原生已验收。

Swan单独验收：真实墙面三角网格和桌面配准、光学眼手/手势射线、近手操控、坐站距离、80–90%平视、晕动和首玩难度/时长。模拟器不能替代这些。首次启动若异常，按本项目日志区分原因，不直接套用过去PICO工单结论。
