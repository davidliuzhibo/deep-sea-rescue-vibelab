# 深海救援站 · 一条安全归途

手势优先、坐姿或原地站姿的 MR 游戏。本版包含四项相连的任务，不再只是一只海龟的救援片段。开发与离线测试候选为 **1.0.0-full-rc1 / versionCode 2**；原生渲染、系统输入、声音听感和 Swan 验收待安排。首玩目标 15–25 分钟尚未实测，不用等待倒计时凑时长。

## 四项任务

1. 海龟解困：检查三处、夹稳木梁、按序剪绳、挂浮袋、绕梁并分段提升。
2. 修复引航灯：先断电换电芯，再调三只互相联动的导光轮，三段传光完成后记为修复。
3. 双浮袋清障：观察配重在哪一侧，调平两袋，分段提升、平移和锁定。升起后禁止随意调气；回托架后可重新调整。
4. 归途护送：三段水域分别绕岩与避横流，修改航标后明确放行。动物沿真实有限速路径行进，实际抵达才进入下一段。

解困后，第 2、3 项可任选先后；两项完成才开放护送。总成果和最好记录保留，可重玩。正在进行的任务先继续、重开或保存退出，不能无提示跳关丢掉进度。重开只清本次尝试。

## 交互与放置

寻找前方墙面，预览完整观察窗再确认；桌面控制台可选。没有适合表面时，明确进入“虚拟练习”。真实平面需要方向、距离、网格覆盖和稳定身份共同通过，不把练习平面当作扫描成功。

所有任务都可用系统眼手点击或手势射线完成。目标点选只高亮，机械臂有限速度对准后再执行。圆柄慢拖是备选，无控制器依赖、不要求精确腕转。暂停、后台、取消及追踪丢失停止运动，恢复后需要明确继续。

## 构建

- 包名：`com.example.deepsearescue.pcd0b39b0`。
- Kotlin 2.1.20、AGP 8.13.2、PICO Spatial SDK 6.1.9、Android SDK 35、arm64-v8a，JDK 21。
- 本机 SDK 路径写在 `local.properties`，不包含在源码交付中。
- release 目前为本机 Android Debug 签名的内部候选；尚未固定商店发布身份，未提交。
- 游戏运行离线，无账号、业务服务器或联网 AI。Seed3D 仅在制作阶段用于海龟资产，运行和构建不需要生成 Key。

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug assembleRelease assembleDebugAndroidTest lintDebug --no-daemon --max-workers=2
```

JSON 设计是面板结构和文案的唯一来源；Native RescueEngine 负责规则。网页 fixture 只是设计预览，Blender 图只是离线构图，不能作原生截图。AndroidTest 已编译，未经设备执行。
