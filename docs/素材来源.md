# 素材来源

- 海龟：火山方舟 Seed3D，由项目自己生成的参考图生成，骨骼动画在 Blender 里制作。
- 其他模型（观察窗、机械臂、工具、礁石、灯标、网笼、航标等）：原项目用 Blender 脚本原创建模，脚本在 `art/deep-sea-rescue/`。
- 环境光：`art/deep-sea-rescue/build_support.py` 程序生成。
- 配乐（1.1.0 起）：Aquaria，作者 cynicmusic，CC0，https://opengameart.org/content/aquaria 。文件 `assets/audio/music.ogg`，已做响度统一。其他候选的试听版在 `docs/音乐候选/`，都是 OpenGameArt 的 CC0 作品：Drifting（some-weirdo）、Underwater（Cleyton RX）、Underwater Ambient Pad（isaiah658）。
- 海底环境声和音效：原项目原创合成。
- 商店图标和海报：图标用海龟参考图，海报由火山方舟 Seedream 生成。
